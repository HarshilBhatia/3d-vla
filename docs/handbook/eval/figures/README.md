# Eval geometry figures

Model-independent illustrations of what miscalibration and camera motion do to
the scene. They explain the [protocols](../protocols.md) and
[miscalibration](../miscalibration.md) pages, so they sit with the handbook
rather than with any experiment or result.

The `.npz` scene captures are **inputs** to the Rerun viz scripts, not outputs.
`.rrd` recordings are not committed; regenerate them with the script listed.

| Figure | Shows | Script |
|---|---|---|
| `scaled_calibration_camera_frusta.{png,pdf}` | Camera frusta under scaled calibration error | `scripts/plot_scaled_calibration_geometry.py` |
| `scaled_calibration_pointcloud_overlays.{png,pdf}` | Overlaid point clouds at each error level | same |
| `scaled_calibration_translation_only{,_3d}.{png,pdf}` | Translation-only error, 2D and 3D views | same |
| `g7_opposite_camera_translation_3d.{png,pdf}` | 3D geometry of the opposing-translation conditions | `scripts/plot_g7_opposite_translation.py` |
| `g7_pick_laptop_scene_pointcloud.{npz,png}` | Captured pick-laptop scene; the `.npz` feeds the viz scripts | `scripts/plot_capture_g7_scene.py` |
| `g7_pick_laptop_scene_pointcloud_500cm.{npz,png}` | The same scene at the 500 cm condition | `scripts/eval/capture_g7_500cm.slurm` |
| `g7_perturbations{.rrd,_preview.png}` | Rerun recording of the perturbation set | `scripts/viz_g7_perturbations_rerun.py` |
| `g7_opposite_camera.rrd`, `g7_rotation_only.rrd` | Rerun recordings of those two condition sets | ad-hoc `scripts/viz_g7_*_rerun.py` runs |

`scripts/plot_g7_opposite_translation.py` also emits
`g7_opposite_camera_pointcloud_3d.{png,pdf}`; those were deleted and are
regenerated by re-running it.
